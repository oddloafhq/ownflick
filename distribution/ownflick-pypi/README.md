# OwnFlick

OwnFlick is the new name for Spooly, a private, self-hosted feed for your own
videos, photos, and music. This package installs the application and provides
the `ownflick` command through its `spooly` dependency. The old `spooly`
installation and command remain supported.

```bash
pip install ownflick
ownflick ~/Videos
```

The application is maintained by [Oddloaf](https://oddloaf.dev) at
[oddloafhq/ownflick](https://github.com/oddloafhq/ownflick).
